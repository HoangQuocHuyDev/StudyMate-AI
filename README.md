# StudyMate AI

Website hỗ trợ tóm tắt và tra cứu tài liệu học tập dành cho sinh viên.

## Công nghệ sử dụng
- Frontend: React + Vite
- Backend: Python + FastAPI
- AI: Google Gemini API
- RAG: Retrieval-Augmented Generation

## Chức năng dự kiến
- Tải lên tài liệu học tập
- Tóm tắt tài liệu bằng AI
- Đặt câu hỏi và tra cứu nội dung tài liệu
- Hỗ trợ sinh viên tiết kiệm thời gian nghiên cứu

## Hướng dẫn cài đặt

### 1. Clone repository
git clone https://github.com/QuocHuyVipPro/StudyMate-AI.git

### 2. Cài đặt Frontend
cd frontend
npm install
npm run dev

### 3. Cài đặt Backend
cd backend
python -m venv .venv
